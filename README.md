# ОПДП — корпусная мебель

Статическая мини-апп форма для заявок на корпусную мебель. Публикация настроена через GitHub Pages Actions.

После загрузки файлов в репозиторий на ветку `main` включите GitHub Pages в **Settings → Pages → Build and deployment → Source → GitHub Actions**. Рабочий процесс `.github/workflows/pages.yml` опубликует сайт.

Перед подключением в MAX проверьте, что публичный адрес `https://<владелец>.github.io/<репозиторий>/` открывается по HTTPS, затем укажите его в **MAX для партнёров → Чат-боты → ваш бот → Настройки → ссылка мини-приложения**.
